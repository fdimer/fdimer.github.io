Three-Cell FPGA

An FPGA small enough to see all of: three logic cells, each a 3-input look-up table and a flip-flop, joined by a lattice of routing switches. Click any stored bit, input or switch, press Clock, and watch the circuit and its bitstream change.

Open Three-Cell FPGA Read FPGAs for beginners

Features

  • Look-up tables: each cell's 8 stored bits are its truth table; click one to change it, and the row the inputs select lights up
  • Routing switches: six tracks carry the pins A, B, C and the three cell outputs; each LUT input picks one track through a column of switches, like a multiplexer
  • Flip-flops and a clock: each cell can send its output through its flip-flop or straight out; Clock loads every flip-flop at once
  • The bitstream: all 54 configuration bits are shown live, so every click is a visible change to the chip's configuration
  • Ready-made circuits: a 3-bit counter, a shift register, a majority gate and a blank chip; a loop with no flip-flop is reported as oscillating
