Three-Cell FPGA

Three logic cells, each a 3-input LUT and a flip-flop, joined by a lattice of routing switches. Click any stored bit, input or switch, then press Clock. It starts as a 3-bit counter.

clock edges 0

Configuration bitstream

LUT bits (8 per cell, address 7 to 0)switch selects (3 bits per LUT input)use flip-flop (1 per cell)

How it works

  • The six horizontal tracks carry the pins A, B, C and the three cell outputs. Orange means 1.
  • Each LUT input picks one track through a column of switches, like a multiplexer: closing one switch opens the others in that column. An unconnected input reads 0.
  • The inputs in2 in1 in0 form an address; the LUT outputs the bit stored there. Click a bit to change the truth table.
  • With the flip-flop on, a cell's output changes only on Clock. With it off, the output follows the LUT at once. A loop of cells with the flip-flops off can oscillate, as in real hardware.
  • Everything you click is one of the 54 configuration bits listed above: this is the whole bitstream for the chip.
