SimpleLetters

A plain word processor: one A4 page, and you write on it. The only things you can change are the margins and the font size.

Try the browser version

Features

  • One page, nothing else: no menus full of options, no styles, no ribbons. Just the page and your words
  • Margins you can see: four arrows around the page mark the margins. Click one to show a line where it is, and drag it to move it
  • Text size: the − and + buttons set the size of what you type next. Text already on the page keeps its size
  • Open, save and print: letters are saved as .sletter files, plain XML that's easy to read without the app. Plain .txt files open too
  • Easy to read: text is set in Atkinson Hyperlegible Next, designed by the Braille Institute for legibility
  • Private: collects no data, and your writing stays on your computer

Windows app

The full version is a Windows app built with C# and WPF, coming soon to the Microsoft Store. The browser version above is an earlier, simpler one: margins and a single text size for the whole page, with no saving to .sletter files.

Source

The Windows version is a .NET 10 WPF app; the browser version is plain HTML, CSS and JavaScript. MIT licence. Built with Claude Code.
