TextBrowser

A web browser that shows only the text of a page, with the look of a 1980s computer terminal. No pictures, no video, no adverts, just words and links.

Download (ZIP)

Features

  • Text only: images, video, audio, scripts and page styling are never loaded or shown
  • Terminal look: phosphor text on a black screen, inverse-video status bars and a blinking block cursor. Press F2 to switch between green, amber and white
  • Links: numbered like Teleprinter[69]. Click one, Tab to it, or type its number at the URL> prompt
  • Search: type words instead of an address to search DuckDuckGo Lite
  • Keyboard friendly: back, forward, reload and scrolling all have keys. Press F1 for the list

Running it

TextBrowser is a desktop app, so it runs on your computer rather than in this page. It needs Python 3 and nothing else. Unzip the download, then run this in that folder:

python textbrowser.py

If some secure (HTTPS) sites show a certificate error, also run pip install truststore.
