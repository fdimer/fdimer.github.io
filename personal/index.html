Personal projects

Hardware and retro-computing tinkering: emulators built from the original chips and schematics, and tools for designing fonts.

Z80 Bench

A Z80 emulator for debugging and designing hardware, with a clickable pinout, hex and assembler input, configurable memory and step-by-step execution.

emulator · hardware

6502 Bench

The same bench built around the NMOS 6502: clickable pinout, assembler and hex input, a ROM, RAM and I/O memory map, and cycle-by-cycle stepping.

emulator · hardware

Osborne Executive

An emulator of the 1983 Osborne Executive built on Z80 Bench from the original schematics: the real ROM, amber screen, keyboard and live chip pinouts.

emulator · retro computer

Sinclair ZX80 and ZX81

An emulator of Sinclair's ZX80 and ZX81 built on Z80 Bench, where the Z80 draws the TV picture itself: the real ROMs, BASIC, SLOW mode, tape files, and the video logic laid bare.

emulator · retro computer

Font Developer

Design your own font in the browser. Draw each character with pixels, lines and arcs, watch the result as you go, and export a .ttf font.

fonts · design
