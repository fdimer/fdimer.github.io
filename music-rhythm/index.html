SimpleMusic Rhythm

A rhythm editor for beginners. Write a rhythm freely without thinking about bars, choose a time signature, and let the app sort the rest out. A sister app of SimpleMusic.

Open the editor

Features

  • Write freely: put notes on a single-line rhythm staff, with no need to count bars as you go
  • Bars done for you: choose a time signature and the rhythm is divided into bars, with notes that cross a bar line tied automatically
  • Strong beats marked: the first beat of each bar gets an accent (>) so you can feel where the bar starts
  • Metronome: use it on its own in any time signature, or let it click along while your rhythm plays

Windows app

SimpleMusic Rhythm is also a Windows app, coming soon to the Microsoft Store.

Source

The browser version is plain HTML, CSS and JavaScript, with no libraries or build step. The Windows app is a .NET 10 WPF app with MSIX packaging for the Store. Built with Claude Code.
