6502 Bench

The sister project to Z80 Bench: the same bench, built around the NMOS 6502. Debug programs and design hardware right in your browser, with nothing to install.

Open the emulator

Features

  • Pinout: a 40-pin view that updates every clock cycle. Click φ0, RDY, /IRQ, /NMI, /SO and /RES to drive them by hand
  • Program input: standard 6502 assembler with labels, directives and automatic zero-page addressing, or raw hex and Intel HEX. You can also import .asm, .hex or .bin files and choose the address they load at, for example the start of ROM
  • Memory map: RAM from 0000h, write-protected ROM up to FFFFh with the reset, NMI and IRQ vectors, and a block of 16 memory-mapped I/O registers
  • Memory: a scrolling view you can edit that follows the instruction being executed
  • Disassembly: scrolls through all of memory and keeps the current instruction in view as you step. Loading hex or a ROM image also turns it into labelled source you can edit and reassemble
  • Stepping: one cycle, one instruction, or run at 5 Hz, 50 Hz, 1 kHz, 5 kHz, 10 kHz or full speed, with breakpoints that stop before an instruction or when the PC leaves it, and register stops that halt when a register changes to a value you choose
  • Debug pane: every breakpoint and stop in one list, plus memory stops (halt when a byte changes, or changes to a value) pin stops (halt when a pin changes, goes high or goes low) and bus stops (halt when the address or data bus takes a value)
  • Bus timing: every bus cycle of the current instruction, including the dummy reads and writes real hardware sees
  • Layout: the registers and bus timing panels fold away to give memory and disassembly more room

Verified

Passes Klaus Dormann's 6502 functional test and all 1.51 million SingleStepTests cases, cycle by cycle, including decimal mode.
