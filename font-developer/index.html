Font Developer

Design a font in your browser. Pick a character, draw it on the left with pixels, lines and arcs, and see the result on the right as you go. When you're done, export it as a TrueType font you can install and use anywhere.

Open Font Developer

Features

  • Pixel drawing: paint on a grid for blocky, bitmap-style letters. The right mouse button rubs out
  • Lines and arcs: draw strokes with a chosen width and round or flat ends, then move them or drag their handles to reshape them. Pixels and strokes can be mixed in one letter
  • Live result: a large preview of the current character, sample text you can edit at four sizes, and a grid of every character, all using the font as it's being built
  • Guides: baseline, x-height, cap height, ascender and descender lines, snap to grid, and a faint letter behind to trace over
  • Export .ttf: builds a real TrueType font from every character you've drawn
  • Save and open projects: as .fontdev.json files, with undo and redo, plus copy and paste between characters
  • Private: everything happens in your browser; nothing is sent anywhere

Source

Plain HTML, CSS and JavaScript with no libraries, including its own TrueType font writer. It covers the basic Latin characters (space to ~) and one regular style. Built with Claude Code.
