MSX: Sony HB-55P

An emulator of the MSX home computer, set up as Sony's 1984 HB-55P and HB-75P and built on Z80 Bench. An MSX is a Z80 with three support chips: a TMS9929A video processor with its own video memory, an 8255 that switches memory slots and reads the keyboard, and an AY-3-8910 sound generator. The emulator runs the real BIOS and MSX BASIC, and shows what each chip is doing while it runs.

Open the emulator

Features

  • Two machines: the Sony HB-55P with 16K of RAM and the HB-75P with 64K, with memory slots switched through the 8255 as on the real machines
  • The real ROMs: load your own 32 KB BIOS and BASIC ROM and, if you like, Sony's 16 KB Personal Data Bank firmware (they aren't included); your browser remembers them
  • Video: the TMS9929A's four screen modes and 32 sprites, drawn line by line as the CPU runs, with the frame interrupt 50 times a second
  • Keyboard: type on your keyboard, mapped by key position to the MSX international layout, or click the on-screen MSX keyboard
  • Cartridges: plain ROM cartridges and the Konami, Konami SCC, ASCII 8K and ASCII 16K mega-ROM mappers
  • Tape: insert a .cas tape file and CLOAD, BLOAD or RUN"CAS:" load instantly; CSAVE, BSAVE and SAVE record to a new .cas file you can download
  • Memory bitmap: every bit of the ROMs, the RAM and the video RAM as a pixel, tinted by use: BASIC's program, variables and stack, and the video processor's screen, pattern, colour and sprite tables
  • Dumps: save the RAM or the video RAM as a binary file, or a readable listing with the system variables, the BASIC program as text, the screen and hex dumps
  • Debugging: Z80 Bench's tools, including the pinout, bus timing, disassembler, breakpoints and stepping, plus a panel showing the slots, the video processor's registers, the 8255 and the sound chip's registers
  • Real time: 3.58 MHz, or full speed. Sound is not played yet
