> RUN EMULATORS

Emulators

Chip benches for debugging and designing hardware, and retro computers rebuilt from their original schematics. All run in your browser, and all grew out of Z80 Bench.

Z80 Bench

A Z80 emulator for debugging and designing hardware, with a clickable pinout, hex and assembler input, configurable memory and step-by-step execution.

emulator · hardware

6502 Bench

The same bench built around the NMOS 6502: clickable pinout, assembler and hex input, a ROM, RAM and I/O memory map, and cycle-by-cycle stepping.

emulator · hardware

Osborne Executive

An emulator of the 1983 Osborne Executive built on Z80 Bench from the original schematics: the real ROM, floppy disks that boot CP/M Plus, amber screen, keyboard and live chip pinouts.

emulator · retro computer

Sinclair ZX80 and ZX81

An emulator of Sinclair's ZX80 and ZX81 built on Z80 Bench, where the Z80 draws the TV picture itself: the real ROMs, BASIC, SLOW mode, tape files, and the video logic laid bare.

emulator · retro computer

MSX: Sony HB-55P

An MSX home computer built on Z80 Bench: the real BIOS and MSX BASIC, the TMS9929A video processor with sprites, memory slots, cartridges and tape files, with every chip open for inspection.

emulator · retro computer

Amstrad CPC 464

An Amstrad CPC built on Z80 Bench from the circuit diagram: the real firmware and BASIC, the gate array's wait states and video, the 6845, and pin faults on the memory, gate array and 6845. Work in progress.

emulator · retro computer

Commodore PET 2001-N

A Commodore PET built on 6502 Bench from the Dynamic PET board schematics: the real BASIC and kernal ROMs, the graphic keyboard, .prg programs and sound, with both PIAs and the VIA open for inspection.

emulator · retro computer
