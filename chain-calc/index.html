Chain Calc

A calculator laid out like a tiny spreadsheet. Type up to five numbers, give each one its own operation, and watch the result build up line by line.

Open the calculator

Features

  • One operation per cell: click a cell's button to cycle through + − × ÷. Each operation acts on the result of the cells above it
  • Running result: every row shows the result so far, and the final answer sits at the bottom
  • Forgiving: empty cells are skipped, and dividing by zero or a typo shows a clear Error instead of a wrong number
  • Easy on the eyes: green text on a dark background, in a large monospace font

Windows app

There is also a Windows version built with C# and WPF, coming soon to the Microsoft Store. It works just like the browser version.

Source

The browser version is a single HTML file. The Windows version is a .NET 10 WPF app with unit tests and MSIX packaging. Built with Claude Code.
