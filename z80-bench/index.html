Z80 Bench

A Z80 emulator for debugging and designing hardware around the Zilog Z80.

Features

  • Pinout view with clickable input pins, so you can drive signals by hand
  • Program entry as raw hex or assembler
  • Configurable memory
  • Step-by-step execution to watch exactly what the CPU does

Coming next

Peripheral support is planned.
