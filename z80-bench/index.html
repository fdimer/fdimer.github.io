Z80 Bench

A Z80 emulator for debugging programs and designing hardware around the Zilog Z80. It runs right in your browser, with nothing to install. There is also a sister project for the 6502: 6502 Bench.

Open the emulator

Features

  • Pinout: a 40-pin view that updates every T-state. Click CLK, /INT, /NMI, /WAIT, /BUSREQ and /RESET to drive them by hand
  • Program input: Zilog-syntax assembler with labels and directives, or raw hex and Intel HEX. You can also import .asm, .hex or .bin files and choose the address they load at, for example the start of ROM
  • Memory: 1 to 64 KB installed, with a scrolling view you can edit that follows the instruction being executed
  • Disassembly: scrolls through all of memory and keeps the current instruction in view as you step. Loading hex or a ROM image also turns it into labelled source you can edit and reassemble
  • Stepping: one T-state, one instruction, or run at 5 Hz, 50 Hz, 1 kHz, 5 kHz, 10 kHz or full speed, with breakpoints that stop before an instruction or when the PC leaves it, and register stops that halt when a register changes to a value you choose
  • Debug pane: every breakpoint and stop in one list, plus memory stops (halt when a byte changes, or changes to a value) pin stops (halt when a pin changes, goes high or goes low) and bus stops (halt when the address or data bus takes a value)
  • Bus timing: waveforms of /M1, /MREQ, /IORQ, /RD, /WR and /RFSH for the current instruction. The registers and bus timing panels fold away to give memory and disassembly more room
  • I/O: OUT writes shown as LED latches, and you set what IN returns for each port

Verified

Passes all 67 zexdoc groups, matches datasheet T-state counts, and assembles all 1,136 instruction forms correctly.

Coming next
