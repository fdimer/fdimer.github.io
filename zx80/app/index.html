Click the picture and type, or use the keyboard above: keywords (white, top) come from the key pressed at the K cursor, red symbols need SHIFT, which latches for one key. Enter is NEWLINE and Backspace is RUBOUT (SHIFT+0). Tape: insert a .o program file, then type LOAD (W, then NEW LINE); SAVE (E, then NEW LINE) downloads the program as a .o file. Both are instant. RAM listing gives the system variables, the BASIC program as text and a hex dump. The picture is built the way a TV would, from the ZX80's own sync pulses, so it blanks while BASIC is busy, as on the real machine. The ROM is not included: load your own 4 KB image; your browser keeps it.

Clicking CLK pulses one clock. /INT is level-sensitive, /NMI triggers on a falling edge. Holding /WAIT low inserts wait states; /BUSREQ low floats the buses at the end of the current machine cycle; /RESET low holds the CPU in reset.

Program

Standard Zilog syntax, one instruction per line. Labels end with :; comments start with ;. Directives: ORG, EQU, DB, DW, DS, END. Numbers: 1Fh, 0x1F, $1F, %1010, 'A', and $ for the current address. Undocumented instructions (IXH, SLL, OUT (C),0) are accepted. Code starts at the Load at address; an ORG in the source overrides it. Import a file with the button or by dropping it on the editor.

Hex bytes separated by spaces or newlines. Text after ; is ignored. Write 0100: to continue loading at another address. Intel HEX files (lines starting with :) are also accepted and keep their own addresses. Raw binary ROM images (.bin, .rom) import here as hex. Scroll through all 64 KB. Click a byte to edit it. Blue marks the instruction being executed, amber marks bytes written by the last instruction, underline marks the top of the stack. Debug

h h

    Every breakpoint and stop appears here, including those set from the disassembly and registers; click one to jump to it. A memory stop halts after the instruction that changes the byte. A pin or bus stop halts on the clock where the pin changes or the bus takes the value, so while one is set, full speed runs clock by clock and is slower.

    Video logic ZX80 TTL

    Opcode fetches above 8000h with bit 6 clear are characters: the CPU gets a NOP (watch D0–D7 read 00 in the bus timing), the byte is latched, and the refresh address I:R plus the line counter picks the font row from the ROM. /INT is A6 of the refresh address; each interrupt acknowledge advances the line counter and sends horizontal sync. Reading port FEh starts vertical sync, any write ends it.
