Sinclair ZX80 and ZX81

An emulator of Sinclair's 1980 home computer, built on Z80 Bench. The ZX80 has no video chip: the Z80 itself runs through the display file, and a handful of logic chips turn its refresh cycles into a TV picture. This emulator models that trick cycle by cycle, so the picture comes from the CPU exactly as on the real machine. It also emulates the ZX81, whose ULA chip adds the NMIs that keep the picture on while BASIC runs, and the ZX80 fitted with the 8K ROM upgrade.

Features

  • Three machines: the ZX80 with its 4K Integer BASIC, the ZX80 with the 8K ROM upgrade (ZX81 BASIC in FAST mode only, as the real upgrade worked) and the ZX81
  • The real ROMs: load your own 4 KB ZX80 and 8 KB ZX81 ROM images (they aren't included); your browser remembers them
  • ZX81 SLOW mode: the ULA's NMI on every line counts the blank margins while your program runs, and holds /WAIT when the NMI meets a HALT, so each picture starts on time. FAST mode blanks the screen while BASIC works
  • Video from the CPU: character bytes become NOPs, the font is fetched during refresh cycles, HALT and the interrupt end each line, and a virtual TV locks onto the sync pulses. The screen blanks while BASIC is busy, just as the real one does
  • Keyboard: type on your keyboard, or click the on-screen keys, which show each key's BASIC keyword, SHIFT symbol and (on the ZX81) FUNCTION word from the ROM's own tables
  • Tape: LOAD and SAVE programs instantly as standard .o (ZX80) and .p (ZX81) files: insert a file and type LOAD, or SAVE and the program downloads. The emulator picks the right machine for the file and plugs in the 16K RAM pack when a program needs it
  • Memory: 1K as supplied, 2K as in the Timex Sinclair 1000, or a 16K, 32K or 48K RAM pack, plus an optional hi-res board: 8K of RAM at 2000h that answers the Z80's refresh cycles, as the SCRAM and WRX boards did, so programs can draw true high-resolution pictures. Dump the RAM as a binary file, or as a readable listing with the system variables, memory areas, the BASIC program as text and a hex dump
  • Memory chips and faults: every memory chip with its pins live: the ROM, the two 2114s of the built-in 1K (or the single 2K chip of a Timex Sinclair 1000, read from a real board) and the 4116s of the RAM pack. Click any pin to disconnect it or hold it high or low, and watch what the machine does with a stuck data bit, a dead address line or a missing chip
  • Real time: 3.25 MHz, or full speed
  • Debugging: Z80 Bench's tools, including the disassembler, memory view, breakpoints and stepping, plus a panel showing the video logic: line counter, sync, the character latch and the ZX81's NMI generator
